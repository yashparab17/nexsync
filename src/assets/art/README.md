# Illustrations

The scenes are from [unDraw](https://undraw.co), downloaded from the site and recoloured by hand-run script (no longer in the repo): the
original purple became `var(--primary)` and every other colour a neutral token (`--card`, `--muted`, `--secondary`, `--input`,
`--fg-3`, `--muted-foreground`, `--foreground`, `--info`), so they follow every theme. To add a scene, download it from unDraw in its
default colour and swap its colours the same way. Read unDraw's licence (undraw.co/license) before adding more.
